
# Segundo Cérebro de IA — Cibersegurança

## 1. Tema e objetivo

**Tema:** Cibersegurança.

**Objetivo:** Criar um segundo cérebro com inteligência artificial no NotebookLM para estudar cibersegurança, organizar conhecimentos e aprender usando fontes selecionadas e confiáveis.

## 2. Fontes utilizadas

1. **CERT.br — Cartilha de Segurança para Internet**

   https://www.cartilha.cert.br/palestras/

5. **PortSwigger Web Security Academy**

## 3. Diretriz de comportamento do notebook

O notebook deve atuar como um tutor de cibersegurança. Deve explicar conceitos em linguagem simples, ensinar um assunto por vez, usar as fontes selecionadas, indicar as fontes das informações e fazer perguntas para verificar meu aprendizado. Se as fontes não fornecerem uma resposta, deve informar isso em vez de inventar informações.

## 4. Perguntas, respostas e fontes

### Pergunta 1 — O que é uma ameaça em segurança da informação?

**Resposta:** Uma ameaça é um agente, situação ou ação que pode causar danos, roubar informações ou interromper um serviço. Um exemplo é uma mensagem falsa que tenta convencer alguém a clicar em um link malicioso.

**Fonte:** CERT.br — Cartilha de Segurança para Internet
https://cartilha.cert.br/

### Pergunta 2 — Quais são os principais riscos de segurança em aplicações web?

**Resposta:** Aplicações web podem apresentar riscos como falhas de controle de acesso, problemas de autenticação e configurações inseguras.

**Fonte:** OWASP Top 10 — 2025
https://top10.owasp.org/2025/pt-BR/
